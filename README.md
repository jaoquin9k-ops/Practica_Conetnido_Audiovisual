En el presente proyecto se busca implementar técnicas para la creación de objetos en Java, estas técnicas se usan para poder tener un desarrollo de código mas limpio y ordenado

-En este proyecto se buscó aplicar conceptos como herencia, polimorfismo entre otros, con el objetivo de poder tener una relación entre los objetos creados a partir de una clase Padre.
-Esta aplicación resuelve la necesidad de centralizar y categorizar datos de producción audiovisual que de otro modo estarían dispersos o desestructurados.

Características Principales
Jerarquía de Clases y Herencia: Uso de la clase abstracta "ContenidoAudiovisual" como base común para aplicar polimorfismo en todos los tipos de contenido.
Encapsulamiento
Modelado de Relaciones de POO
Agregación 
Asociación
Polimorfismo
